How evaluation works

  1. Golden evaluation cases are run through the real RAG pipeline.
  2. Retrieval, answer, citation and latency metrics are measured.
  3. Backend scoring applies project-specific regression gates.
  4. CI can reject changes when mandatory gates fail.

These are project-specific regression gates, not universal legal-AI quality standards.
